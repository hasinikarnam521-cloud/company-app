# VentrixCarros

VentrixCarros is a company recruitment website. The frontend uses HTML, CSS, and JavaScript. The backend uses Node.js, Express, Sequelize, and MySQL.

## Requirements

- Node.js and npm
- MySQL and MySQL Workbench
- Visual Studio Code
- Live Server extension for VS Code

## Set up the database

In MySQL Workbench, create the database:

```sql
CREATE DATABASE ventrixcarros;
